WeChat Agent — macOS 13 及以上

1. 将 RpaWx.app 拖入 Applications（应用程序）。不要直接从 DMG 运行。
2. 当前版本为 ad-hoc 签名，没有 Apple Developer ID 签名或公证。
   如果系统阻止打开，请先尝试打开，再到“系统设置 → 隐私与安全性”选择“仍要打开”。
   仅在确认安装包来自项目官方 Release 时继续。
3. 首次绑定窗口时，允许“辅助功能”和“屏幕录制”权限。
   在“系统设置 → 隐私与安全性”中为 RpaWx / WeChat Agent 启用它们，然后退出并重启应用。
4. 将已登录的微信置于当前桌面，点击绑定窗口自动查找主窗口，再校准输入框与发送按钮。
5. 设置微信为 Enter 发送、Shift+Enter 换行。可选择人工审核发送，或点击“开始自动回复”自动检查并打开未读会话、识别和发送回复。
6. 自动模式会占用前台、鼠标和键盘，请暂停其他操作。遇到已有草稿、识别不清、窗口变化时会停止。点击停止，或输入时按住 Esc 中止。

arm64 版本适用于 Apple Silicon（M1、M2 等）；x86_64 适用于 Intel Mac。
程序不内置 API Key。点击主界面右上角“设置”，选择 OpenAI、阿里云百炼或自定义兼容服务，配置 Key、接入地址、截图识别模型和回复模型。
百炼设置中内置 518 个模型条目，点击“浏览 / 搜索”按任务选择模型；“百炼全部模型目录”可查看生图、语音、视频、向量等全部类别。可填写 Key 后同步官方模型目录；开通权限和实际地域可用性以控制台为准。
密钥只在本次运行中保留；模型和接入地址会保存。截图会发送至所选模型服务商。
使用百炼中国站新人免费额度时，请选择北京地域、核对控制台额度并开启“免费额度用完即停”。
当前版本尚未完成 macOS 13 真机微信端到端验收。
