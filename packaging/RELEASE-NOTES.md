## 安装包

- `windows-x64-setup.exe`：Windows 10/11，64 位安装程序。
- `macos-13-arm64.dmg`：macOS 13+，Apple Silicon。
- `macos-13-x86_64.dmg`：macOS 13+，Intel。
- `SHA256SUMS.txt`：文件校验值。

macOS：打开 DMG 后将应用拖入 Applications。需要授予“辅助功能”和“屏幕录制”权限，授权后重启应用。当前 macOS 应用仅 ad-hoc 签名，未经过 Apple Developer ID 签名或公证；Windows 安装包未签名。系统可能显示来源提示。

CI 执行单元测试、界面初始化、安装包构建和打包后启动检查；macOS 额外检查应用内 Mach-O 二进制最低系统版本不高于 13.0。已在 macOS 13.7.8 / 微信 4.1.15 上只读验证进程和主窗口识别；真实微信 API 识别、输入和自动发送仍需配置 API Key 后验收。

需要自行提供所选服务商的 API Key。截图会发送至该模型服务，实际免费额度、有效期和计费以服务商控制台为准。百炼中国站新人免费额度适用北京地域，建议在模型页面开启“免费额度用完即停”。自动模式会直接发送，且可能处理开启前已有的未读及当前对方消息；请使用测试聊天先行验证，运行时保持微信可见并暂停其他电脑操作。没有规避平台检测功能。
