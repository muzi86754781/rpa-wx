Windows 与 macOS 微信桌面助手，支持人工审核和未读会话自动回复。

## 本次更新

- 自动回复只处理头像旁圆形红色背景内带数字的未读角标，代码校验角标类型及正整数（支持 99+）。纯红点、灰色数字、无数字角标的当前聊天不处理；打开后角标消失的待处理会话仍可继续。
- macOS 改用有明确目标坐标、限制步长的像素滚动事件。扫描引擎匹配前后截图，发现实际滚动反向时自动校正；不会按 Mac/Windows 名称简单反转方向。
- 向下扫描改为小步滚动，并在列表靠下位置滚动，减少大步跳行和置顶区域影响。画面不变时反向探测及复位，不能确认到底则报告未完成，避免提前结束漏掉下方会话。
- 增加真实图像位移、反向滚动全列表扫描、边界探测、不响应列表和数字角标筛选测试。本机独立原生滚动窗口已验证像素事件向上/向下及目标位置；未向微信投递测试输入。

## 安装包

- `windows-x64-setup.exe`：Windows 10/11，64 位安装程序。
- `macos-13-arm64.dmg`：macOS 13+，Apple Silicon。
- `macos-13-x86_64.dmg`：macOS 13+，Intel。
- `SHA256SUMS.txt`：文件校验值。

macOS：打开 DMG 后将应用拖入 Applications。需要授予“辅助功能”和“屏幕录制”权限，授权后重启应用。当前 macOS 应用仅 ad-hoc 签名，未经过 Apple Developer ID 签名或公证；Windows 安装包未签名。系统可能显示来源提示。

CI 执行单元测试、界面初始化、安装包构建和打包后启动检查；macOS 额外检查应用内 Mach-O 二进制最低系统版本不高于 13.0。已在 macOS 13.7.8 / 微信 4.1.15 上只读验证进程和主窗口识别；真实微信 API 识别、输入和自动发送仍需配置 API Key 后验收。

需要自行提供所选服务商的 API Key。截图会发送至该模型服务，实际免费额度、有效期和计费以服务商控制台为准。百炼中国站新人免费额度适用北京地域，建议在模型页面开启“免费额度用完即停”。自动模式会直接发送，可能处理开启前已有的数字红角标未读；请使用测试聊天先行验证，运行时保持微信可见并暂停其他电脑操作。没有规避平台检测功能。
